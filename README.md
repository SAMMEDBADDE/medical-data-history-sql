# Medical Data History SQL Project

A capstone project using MySQL to explore medical history data with SQL queries. The queries examine patients, admissions, doctors, and province names, and the accompanying report includes query results.

## Project files

- `Medical Data History.sql` — SQL queries for the project tasks.
- `Medical Data History Report.docx` — report with task descriptions and result screenshots.

## Database tables

The queries use these tables in the `project_medical_data_history` database:

- `patients`
- `admissions`
- `doctors`
- `province_names`

The dataset is accessed from the project’s MySQL database and is not included in this repository.

## Topics covered

The queries demonstrate filtering, sorting, joins, aggregation, date functions, string formatting, common table expressions, and patient statistics.

## Running the queries

1. Connect to the MySQL database using an authorized MySQL client.
2. Open `Medical Data History.sql`.
3. Select and run the queries individually.
4. Compare the output with the screenshots in the report.

The shared database account may not allow data changes. For example, the allergy update query requires `UPDATE` permission. Do not include database passwords or other credentials in this repository.

## Notes

This project is for learning and demonstration. Use the database only with authorized access.
